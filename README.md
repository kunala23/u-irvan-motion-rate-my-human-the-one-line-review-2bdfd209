A tiny deterministic program that writes the one-line review its AI agent would leave about its human on a rating site. It scores a shortlist of candidate lines against the judge's published brief — agent's voice first, a real joke with a turn, the machine's side of the desk, one concrete detail, no padding and a last word that pays off — and writes the best line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
